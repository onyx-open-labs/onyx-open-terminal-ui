# Application icon

`Onyx.ico` uses the existing Onyx Digital website favicon artwork, retrieved on
11 October 2026 from https://onyxdigital.com.au/:

- `assets/img/favicon-16x16.png` (original 16 px frame)
- `assets/img/favicon-32x32.png` (original 32 px frame)
- `assets/img/android-chrome-512x512.png` (source for 48, 64, 128 and 256 px frames)

The artwork, proportions and background are preserved. The same ICO is embedded
in the executable and copied into build and publish output for the window icon.
Windows shortcuts and the uninstall entry use the executable's embedded icon.
